# PipeWire.jl

[![CI](https://github.com/DarrylGamroth/PipeWire.jl/actions/workflows/ci.yml/badge.svg)](https://github.com/DarrylGamroth/PipeWire.jl/actions/workflows/ci.yml)

Julia bindings for the PipeWire client API.

The package is being built in layers:

- `PipeWire_jll` supplies reproducible Linux artifacts.
- `PipeWire.LibPipeWire` is the thin, unsafe C ABI layer generated by
  [Clang.jl](https://github.com/JuliaInterop/Clang.jl).
- owning Julia types provide deterministic cleanup and an idiomatic public API.

The managed API currently includes main loops, contexts, core connections,
registry-global snapshots and binding, generic proxies, native-backed
properties, typed node/port/device/link/metadata/factory/module/client proxies,
streams, owned SPA PODs for raw-audio formats, and mapped stream buffers.
Native resources follow Julia's `close`/`isopen` conventions and enforce
PipeWire's parent-before-child lifetime rules.

```julia
using PipeWire

println(library_version())

with_registry() do registry
    roundtrip(registry)
    for global_object in globals(registry)
        println(global_object.id, " ", global_object.type)
    end
end
```

Typed proxies copy callback-owned info, property, and parameter data into Julia
snapshots. Their callback tuples are type parameters, like stream callbacks.

```julia
with_registry() do registry
    roundtrip(registry)
    metadata_global = first(
        global_object for global_object in globals(registry) if
        global_object.type == "PipeWire:Interface:Metadata"
    )
    metadata = bind(registry, metadata_global, Metadata;
        on_property=(metadata, subject, key, type, value) ->
            println(subject, " ", key, " = ", value))
    try
        roundtrip(metadata)
    finally
        close(metadata)
    end
end
```

Objects can also be created from server factories. Core-created proxies retain
their core and must be closed or destroyed before it.

```julia
metadata = create_object(
    core,
    "metadata",
    Metadata;
    properties=Dict("metadata.name" => "julia.settings"),
)
try
    roundtrip(metadata)
finally
    destroy_object!(core, metadata)
end
```

`with_registry` connects to the default PipeWire daemon. For an embedded
in-process core, use `with_registry(self=true)`.

## Raw-audio stream

Stream callbacks are stored in the concrete `Stream` type. A zero-allocating
callable and a reusable `StreamBuffer` therefore keep the steady-state process
callback allocation-free after warmup. Do not request `RT_PROCESS`: Julia
callbacks are not hard-real-time safe.

```julia
using PipeWire

mutable struct SineProcess
    buffer::StreamBuffer
    phase::Float32
end

function (process::SineProcess)(stream::Stream)
    dequeue_buffer!(process.buffer, stream) || return
    plane = buffer_data(process.buffer)
    frames = capacity(plane) ÷ (2 * sizeof(Float32))
    samples = Ptr{Float32}(data_pointer(plane))

    for frame in 1:frames
        sample = 0.1f0 * sin(process.phase)
        unsafe_store!(samples, sample, 2frame - 1)
        unsafe_store!(samples, sample, 2frame)
        process.phase += 2f0 * Float32(pi) * 440f0 / 48_000f0
    end

    set_chunk!(plane; size=frames * 2 * sizeof(Float32), stride=2 * sizeof(Float32))
    queue_buffer!(process.buffer, stream)
    return
end

context = Context()
core = CoreConnection(context)
process = SineProcess(StreamBuffer(), 0f0)
stream = Stream(
    core,
    "Julia sine";
    properties=Dict(
        "media.type" => "Audio",
        "media.category" => "Playback",
        "media.role" => "Music",
    ),
    on_process=process,
)

try
    connect!(stream, :output; params=[audio_format(format=Audio.F32, rate=48_000, channels=2)])
    run!(stream)
finally
    close(stream)
    close(core)
    close(context)
end
```

The generated `PipeWire.LibPipeWire` module remains available for client APIs
that do not yet have a managed wrapper. General SPA POD construction/parsing,
client permission mutation, and video-format APIs are still in progress.

Until `PipeWire_jll` is registered, add its public wrapper repository before
instantiating:

```sh
julia --project=. -e 'using Pkg; Pkg.develop(url="https://github.com/DarrylGamroth/PipeWire_jll.jl"); Pkg.instantiate(); Pkg.test()'
```

## Regenerating the C bindings

The checked-in `src/generated/LibPipeWire.jl` file is generated from the
PipeWire client, extension, and SPA format headers shipped by `PipeWire_jll`.
Do not edit it by hand. After changing the JLL or generator configuration,
regenerate it with:

```sh
julia --project=gen -e 'using Pkg; Pkg.develop(path=joinpath(homedir(), ".julia", "dev", "PipeWire_jll")); Pkg.instantiate()'
julia --project=gen gen/generator.jl
```

The generator environment is separate from the runtime package, so Clang.jl
is not a dependency of PipeWire.jl users.
